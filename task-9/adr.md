### <a name="_qmphm5d6rvi3"></a>**Решение**

`Products` - Допустимая задержка репликации: 1-3 секунды

| Операция чтения | Primary/Secondary | Обоснование |
|---|---|---|
| Поиск товаров по категориям | Secondary | Каталожные данные, допустима небольшая задержка |
| Фильтрация товаров по цене | Secondary | Статические данные, не критично к актуальности |
| Отображение описания товара | Secondary | Описания изменяются редко |
| Просмотр каталога товаров | Secondary | Массовые операции чтения, можно распределить нагрузку |
| Проверка остатков при заказе | **Primary** | Критично для предотвращения продажи сверх доступных объемов |
| Получение актуальных остатков | **Primary** | Данные обновляются очень часто |
| Проверка доступности товара | **Primary** | Влияет на возможность покупки |

--

`Orders` - Допустимая задержка репликации: 2-5 секунд

| Операция чтения | Primary/Secondary | Обоснование |
|---|---|---|
| История заказов пользователя | - | Используется таблица `orders_history` |
| Список заказов в личном кабинете | - | Используется таблица `orders_history` |
| Поиск заказов по фильтрам | Secondary | Аналитические запросы |
| Отображение текущего статуса заказа | **Primary** | Критично для пользователя и логистики |
| Проверка статуса при обновлении | **Primary** | Влияет на бизнес-процессы |
| Операции с оплатой и подтверждением | **Primary** | Финансовые операции требуют точности |
| Проверка возможности отмены заказа | **Primary** | Зависит от актуального статуса |

--

`Carts` - Допустимая задержка репликации: 0.5-1 секунда

| Операция чтения | Primary/Secondary | Обоснование |
|---|---|---|
| Отображение содержимого корзины | **Primary** | Пользователь ожидает мгновенного отражения изменений |
| Получение корзины перед добавлением товара | **Primary** | Риск дублирования товаров |
| Получение корзины перед оформлением заказа | **Primary** | Критично для точности заказа |
| Подсчет общей стоимости корзины | **Primary** | Влияет на финансовые расчеты |
| Слияние гостевой и пользовательской корзины | **Primary** | Риск потери данных |
| Проверка корзины при любых изменениях | **Primary** | Операции выполняются последовательно |
